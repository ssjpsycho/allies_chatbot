# allies_chatbot
AI Chatbot of Allies of Majesty

## Open the project in VS Code

From a terminal on your local computer, clone the repository and open the
working copy in VS Code:

```bash
git clone https://github.com/ssjpsycho/allies_chatbot.git
cd allies_chatbot
code .
```

If the project is already cloned, open its directory with `code .` and pull
the latest changes from the current branch:

```bash
git pull
```
